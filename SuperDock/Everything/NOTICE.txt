2. ES command line client (es.exe)
   File: es.exe
   Source: https://www.voidtools.com/es.zip
   Used to query Everything instances that run with a custom -instance name,
   which the Everything SDK v2 cannot address.

Everything is started in the background only when no usable Everything
instance is already running. Its configuration and index database are stored
under %LOCALAPPDATA%\Superun\Everything, not inside the install directory.
